# Repwise

### Local-first workout tracking, built for consistency.

Repwise is a **mobile-first Progressive Web App (PWA)** for creating workout routines, logging workouts, tracking personal records, and monitoring progress.

It follows a **local-first architecture**, meaning your workout data is stored directly on your device and the app works offline. Optional Google Drive backup allows you to keep a recoverable copy of your data without requiring a dedicated backend.

## ✨ Features

* 🤖 **AI Routine Import** — Import workout routines generated by ChatGPT, Claude, Gemini, or other AI tools using JSON. Exercises, muscle groups, and equipment are automatically normalized.
* ⚔️ **Conflict Resolution** — Handle duplicate routines during AI imports by renaming or overwriting existing routines.
* 🛡️ **Capacity Limits** — Supports up to **10 routines** and **20 custom exercises** to keep local storage lightweight and manageable.
* 🏋️ **Workout Routines** — Create, reorder, plan, and organize reusable workout routines.
* 📝 **Workout Logging** — Track sets, reps, weight, and set types such as warm-up, normal, drop set, and failure.
* 👻 **Ghost Sets** — Automatically show previous workout performance while logging a new session.
* 🏆 **Personal Records** — Track your best performance for each exercise.
* 📈 **Progress Tracking** — Monitor strength, workout volume, and estimated 1RM over time.
* 🔥 **Workout Streaks** — Track workout consistency and frequency.
* ⚖️ **Body Weight Tracking** — Record and visualize body-weight changes over time.
* ⏱️ **Rest Timer** — Built-in rest timer with configurable preferences and automatic triggering after completed sets.
* 📴 **Offline First** — Core functionality works without an internet connection using IndexedDB and Dexie.js.
* ☁️ **Google Drive Backup** — Optional backup and synchronization using your private Google Drive App Data folder.
* 📦 **JSON Backup & Restore** — Export and restore your complete workout data as a portable JSON file.
* 🧹 **Data Purge** — Permanently remove workout history, routines, custom exercises, and other locally stored data.

## 🏗️ Architecture

Repwise follows a **local-first architecture**.

```text
                    Repwise PWA
                         │
                  Next.js + React
                         │
                      Dexie.js
                         │
                     IndexedDB
                         │
              ┌──────────┴──────────┐
              │                     │
         Local Data              Backup
              │                     │
              │              ┌──────┴──────┐
              │              │             │
              │          JSON File    Google Drive
              │
              ▼
          User Device
```

**IndexedDB is the primary source of truth.**

The core application does not require a remote backend or database server. Google Drive is used only as an optional backup and synchronization mechanism.

---

## 📐 Data Constraints & Validation

Repwise uses a few limits to keep local storage lightweight and prevent unnecessary data duplication.

* **Maximum 10 routines** — Users cannot create or import more than 10 routines.
* **Maximum 20 custom exercises** — System-provided exercises are not counted toward this limit. User-created and imported custom exercises count toward the limit.
* **Existing exercise reuse** — Importing a routine that uses an existing exercise does not create another custom exercise.
* **Import state cleanup** — Import data, form inputs, and conflict-resolution state are cleared after an import is completed or cancelled.
* **Complete data purge** — The data purge operation removes routines, workouts, sets, custom exercises, and body-weight records from local storage.

## 🚀 Getting Started

### Prerequisites

* Node.js 18.17 or later
* npm or pnpm
* Git

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/<your-username>/repwise.git
cd repwise
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```

---

## ☁️ Google Drive Backup

Google Drive backup is **optional**. Repwise works without it.

Create a `.env.local` file:

```env
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your-google-client-id
```

### Google Cloud Setup

1. Create a Google Cloud project.
2. Enable the **Google Drive API**.
3. Create an **OAuth 2.0 Client ID** for a web application.
4. Add your development and production URLs as authorized JavaScript origins.
5. Configure the required Google Drive `appDataFolder` scope.
6. Add the client ID to `.env.local`.

If Google Drive is not configured, Repwise continues to work locally and offline.

## 📱 PWA

Repwise can be installed as a Progressive Web App on supported browsers and devices.

For production PWA testing:

```bash
npm run build
npm run start
```

Then open the application in a supported browser and use the browser's **Install App** option.

## 🔐 Data & Privacy

Repwise is designed around **local data ownership**.

* No account is required for normal usage.
* Workout data is stored locally in IndexedDB.
* Core functionality works offline.
* Google Drive backup is optional.
* Google Drive backups use the account's private App Data area.
* Workout data can be exported as a JSON file.
* There is no dedicated backend database required for core functionality.
* Users can permanently delete their locally stored workout data through the application's data purge option.

For more information, see the application's **Privacy Policy** and **Terms** pages.
